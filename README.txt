SPIN WHEEL — versi perbaikan

Cara pakai:
1. Ekstrak folder ZIP.
2. Buka index.html di browser, atau buka folder di VS Code lalu jalankan dengan Live Server.
3. Tambah hadiah, atur bobot peluang di bagian "Peluang hadiah", lalu putar.

Catatan:
- Semua sektor roda tetap sama besar; bobot hanya memengaruhi peluang terpilih.
- Nama kembar diperbolehkan.
- Hasil MegaPrize punya perayaan lebih besar; Beng Beng/Oreo/permen mendapat teks santai.
- Animasi hasil ditampilkan di dalam area roda, termasuk saat layar penuh.
- Data disimpan di browser (localStorage). Gunakan Ekspor data untuk membuat cadangan.

Versi pembaruan: tema navy-biru yang lebih redup, kategori MegaPrize terpisah dari Doorprize biasa, dan kalimat hasil acak dengan variasi lucu.

Tambahan V3: hadiah bertuliskan Zonk/Coba Lagi/Belum Beruntung akan menampilkan ejekan ringan yang acak dan lucu.
